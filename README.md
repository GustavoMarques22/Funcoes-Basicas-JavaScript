# 🚀 Projeto: Funções Básicas em JavaScript

Bem-vindo ao repositório de **exercícios práticos com funções JavaScript**!  
Este projeto é ideal para estudantes e iniciantes que desejam reforçar os conceitos essenciais da linguagem, como:

- 📊 Validações
- 🔢 Operações com números
- 📚 Manipulação de arrays
- 🧩 Comparação de objetos
- 🔄 Uso de condicionais e loops

Ótimo para quem quer fortalecer a lógica de programação com desafios simples e eficazes!

---

## ✨ Funcionalidades Incluídas

### 🔢 Validações Numéricas
- `validarNumero(numero)` → Verifica se o número é **positivo**, **negativo** ou **zero**.
- `verificarIdade(idade)` → Informa se a pessoa é **maior** ou **menor de idade**.
- `verificarAnoBissexto(ano)` → Determina se um **ano é bissexto**.
- `calcularMedia(num1, num2)` → Calcula a **média** entre dois números, validando se são válidos.

### 📝 Validação de Strings
- `validarString(texto)` → Retorna se uma **string está vazia** ou não.

### 🗂️ Manipulação de Arrays
- `obterTamanhoArray(arr)` → Retorna o **tamanho** do array.
- `verificarElementoNoArray(arr, elemento)` → Verifica se um **elemento específico** está presente.
- `verificarObjetoNoArray(arr, objeto)` → Verifica se um **objeto** existe dentro de um array de objetos.
- `calcularSomaProduto(array)` → Calcula:
  - A **soma dos números pares**
  - O **produto dos números ímpares**

## 💻 Como Executar os Códigos

### ✅ Pré-requisitos:
- Tenha o **Node.js** instalado para rodar no terminal
- Ou simplesmente utilize o **console** do navegador (F12 ➔ Console)

### ▶️ Rodando com Node.js:
1. Abra o terminal
2. Execute:
```bash
node seu-arquivo.js
````

### 🔎 Testando no Navegador:

* Copie e cole as funções diretamente no **Console** da aba de DevTools.

---

## 📚 Exemplos Rápidos

```javascript
console.log(validarNumero(-1)); // Saída: "Negativo"
console.log(verificarIdade(18)); // Saída: "Maior de idade"
console.log(validarString("Olá mundo")); // Saída: "String não vazia"
console.log(verificarAnoBissexto(2024)); // Saída: "Ano bissexto"
console.log(calcularMedia(8, 5)); // Saída: 6.5
```
